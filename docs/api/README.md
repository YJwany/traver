Versioned HTTP contract lives under /api/v1. OpenAPI is generated by FastAPI.

## 端点分组

| 分组 | 路径 | 说明 |
|---|---|---|
| 健康 | `GET /api/v1/health` | 存活 + 真实就绪信号；同时报告认证模式、保险箱状态与主密钥来源 |
| Provider | `GET /api/v1/providers/catalog` | Provider 清单、能力矩阵、缺失凭据、保险箱状态 |
| Provider | `GET /api/v1/providers/health` | 每个 Provider 的请求/成功/失败/超时统计 |
| Provider | `GET /api/v1/providers/attributions` | ODbL / CC BY 4.0 要求的署名 |
| 凭据 | `GET /api/v1/settings/credentials` | 本人已配置的凭据名与来源（`stored` / `env`），**不含值** |
| 凭据 | `PUT /api/v1/settings/credentials/{provider_id}/{credential_key}` | 保存（只写，不回显） |
| 凭据 | `DELETE /api/v1/settings/credentials/{provider_id}/{credential_key}` | 删除，回退到环境变量 |
| 凭据 | `POST /api/v1/settings/model/test` | 真发一次请求测试模型连通性 |
| 行程 | `GET/POST /api/v1/trips` 等 | 行程的创建、读取、修订、列表分页 |
| AI | `POST /api/v1/ai/chat` | 需求理解 + 工具编排；无模型时回落本地确定性规划器 |
| 工具 | `POST /api/v1/tools/{name}` | 直接调用工具；写意图由请求本身推导，不由调用方指定 |

## 认证

除 `/api/v1/health` 外均需 `Authorization: Bearer trv_...`。

- `AUTH_ENABLED=false` 时使用单一合成属主（本机开发），且 `/api/v1/health` 会报告 `"authentication": "disabled"`，未加固的部署不会被误认为已加固。
- 作用域：`trip:read`、`trip:write`。凭据的读写需要 `trip:write`。
- 所有行程与凭据查询都按属主过滤，跨租户读取返回 404、跨租户删除是 no-op。

## 凭据接口的安全约定

- **写只写、读不回显**：没有任何端点能返回已保存的凭据值。想验证有效性请用 `POST /settings/model/test`。
- `provider_id` 与 `credential_key` 必须来自 Provider 清单，否则返回 404——避免错别字写入一条永远没人读的记录，也避免保险箱变成任意键值存储。
- 保险箱不可用时返回 **503**（而非 500）并附可操作原因，例如主密钥格式错误。
- 环境变量是兜底默认，界面保存的值只覆盖保存者本人。若已保存的值无法解密，**不会**回退到环境变量——否则用户的请求会悄悄花掉运维那个 Key 的额度。

加密方式、威胁模型与边界见 [../architecture/credentials.md](../architecture/credentials.md)。
